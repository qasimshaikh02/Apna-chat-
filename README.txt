APNA CHAT — APP PACKAGE

1. index.html is the working Supabase chat app.
2. manifest.webmanifest + sw.js make it installable as a PWA when served over HTTPS.
3. Open index.html directly to test the chat; PWA install requires a web host/HTTPS.
4. The app uses the Supabase URL/key already configured in the existing working HTML.
5. The chat-media bucket created by the SQL upgrade is used for image/video/file uploads.
